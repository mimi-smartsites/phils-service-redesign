# Phil's Service – Website Redesign (design prototype)

Redesign concept for [philsservice.com](https://philsservice.com) (Phil's Service, 503 S 2nd St, Killeen, TX).
This is a **static, front-end prototype** for the dev team to build from. It is not wired to WordPress, forms, or analytics.

- Live preview: https://share.smartsites.com/phils-service/website-redesign
- Client project: SmartSites AC #7607

## Run it

No build step. Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

Then go to http://localhost:8080.

`standalone/phils-service-redesign.html` is the same page with the images embedded, so it works as a single file you can email or drop anywhere.

## What's in the repo

| Path | What it is |
|---|---|
| `index.html` | The whole prototype: markup, CSS and JS in one file. Uses `assets/`. |
| `assets/` | Logo (`logo.svg`, original colors) and the two team photos from the client. |
| `standalone/` | Single-file build with images inlined. |
| `content/live-site-copy.json` | Copy scraped from the live site (home, about, careers, makes landing, 18 service pages, 10 make pages, 4 location pages), as ordered `[tag, text]` blocks. The prototype renders these as-is. |
| `content/blog-posts.json` | The 9 most recent blog posts (full text) from the live WP REST API. |

## How the prototype is built

- **Single page, hash routing.** Each "page" is a `<div data-view="…">`. The router (`route()` near the bottom of the script) shows one view at a time. A garage-door transition (`#door`, `onHash()`) plays between pages.
- **Routes**

  | Hash | Page |
  |---|---|
  | `#home` | Homepage (anchors inside: `#services`, `#makes-band`, `#mclaren`, `#story`, `#reviews-band`, `#club`) |
  | `#all-services` | Services landing |
  | `#svc-{id}` | Service page (18), live copy from `LIVE.svc` |
  | `#vehicles`, `#vehicles-{asian\|domestic\|european}` | Makes landing with search + filter |
  | `#make-{slug}` | Make page. 10 Asian makes use live copy; McLaren has its own specialist page; others use a template |
  | `#areas` | Areas We Serve landing (interactive map) |
  | `#area-{town}` | Town page. Killeen, Copperas Cove, Harker Heights, Nolanville use live copy; others use a template |
  | `#about`, `#careers`, `#reviews`, `#specials`, `#blog`, `#post-{slug}`, `#contact` | Static pages |
  | `#quote-{serviceId}` | Opens Contact with that service pre-selected in the quote form |

- **Design tokens** are CSS custom properties at the top of the first `<style>` block (`--ink`, `--red`, `--red-hot`, `--paper`, `--bay`, `--line`, `--steel`, fonts).
- **Fonts** (Google Fonts): Saira Condensed (display), Figtree (body), JetBrains Mono (labels/data).
- **Icons** are a custom inline SVG sprite (`<symbol id="i-…">`), one per service, stroke-based with a red accent via `--acc`.
- **Blueprint illustrations** in page banners and CTA strips are generated by the `HA()` function (wheel, gears, piston, spark plug, coil-over, speedometer, toolkit, coupon, rating gauge, supercar).
- **Hours** live in one array: `HOURS` (minutes from midnight, Sun–Sat). Mon–Fri 8:00–5:30, Sat 8:00–2:00, Sun closed. The open/closed badges use America/Chicago time.
- **Reduced motion** is respected everywhere (`prefers-reduced-motion`).

## Content rules followed

- Page banners show the short page name. The live site's H1 is kept as the real `<h1>` at the top of the content (SEO).
- Service, make, location, home, about and careers copy is the live site's copy.
- Reviews are **only** 5-star Google and Yelp reviews, shown verbatim (no edits), chosen for similar length so the grid stays even.

## Open items before launch

1. **Forms are front-end only.** Quote form (4 steps), career application (with resume + application uploads, PDF/DOC/DOCX, 10 MB max) and VIP text signup validate in the browser and show a "preview" success state. They need to be connected to Gravity Forms (or whatever the site uses) and the shop's inbox/SMS tool.
2. **McLaren specialist.** Homepage section (`#mclaren`) and `#make-mclaren` use general copy on purpose. Add technician name, certifications and services when the client provides them.
3. **Pages with no live copy yet** (need SEO copy): Reviews page intro, the 19 town pages beyond the 4 live locations, domestic/European make pages, the homepage "Areas we serve" teaser.
4. **Confirm with client:** "Veteran-owned" (from Google Business Profile), GM Master Tech on staff, domestic/European make lists.
5. **Live Google reviews:** consider a reviews widget/API instead of the hard-coded `REVIEWS` array.
6. **Map** is a hand-drawn SVG with approximate town coordinates (`TOWNS` array), not a map API.
7. Live-site typos were kept as-is in the scraped copy (e.g. "Auto Lighting Between & Electrical" in some service headings; duplicate FAQ answers on the 4WD page). Fix in WordPress or here.
